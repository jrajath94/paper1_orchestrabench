## Pre-Submission Checklist

Complete all items before submitting:

- [ ] Paper compiles without LaTeX errors (`/paper:compile`)
- [ ] Submission checker passes (`/paper:submit-check`)
- [ ] All placeholder markers filled with real content (`[PAPER TITLE]`, `[SECTION REF]`, `[AUTHOR NAME]`, etc.)
- [ ] Cover letter reviewed and personalized
- [ ] NeurIPS checklist section references updated with actual section numbers
- [ ] Anonymization verified (no author names, no identifying URLs, no institution names)
- [ ] Page limit verified (9 pages main content, unlimited appendix/references)
- [ ] LLM disclosure reviewed for accuracy
- [ ] Abstract within 250-word limit
- [ ] All figures readable in black-and-white
- [ ] Line numbers included (submission version)
- [ ] No acknowledgments section (submission version)
